ATELIER MATHS — VERSION FULL STACK LOCALE
=======================================

Aucun Python, aucun environnement .venv, aucun pip et aucun npm install.
Seul Node.js (version 18 ou plus) est nécessaire : https://nodejs.org/

1. Décompressez TOUTE l'archive ZIP sur l'ordinateur.
2. Double-cliquez sur OPEN_ATELIER_MATHS.vbs (sans terminal).
3. Le navigateur ouvrira automatiquement http://127.0.0.1:3210/
4. Vous pouvez aussi lancer START_ATELIER_MATHS.bat pour lire les erreurs.

Tous les livres (anglais/français, dont EB7 français) sont dans public/books/.
Les documents et données enregistrés sont sauvegardés dans backend/data/.
Pour changer d'ordinateur, copiez le DOSSIER COMPLET, données comprises.
Pour récupérer une ancienne sauvegarde du site HTML, utilisez Restaurer.

Le serveur est accessible uniquement sur votre ordinateur.
Le site n'est PAS publié sur Internet. ChatGPT reste un service en ligne.
